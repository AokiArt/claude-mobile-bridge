# claude-mobile-bridge

**离开工位，手机继续指挥电脑上的 Claude Code。**

一套飞书 ⇄ 电脑的双端互通工具包：Claude 在电脑上干活，你在手机上**审批操作、下达指令、实时看画面**——所有交互都发生在一个飞书群里，零外网中继、国内网络直连可用。

```
   手机（飞书）                                  电脑（macOS + tmux + Claude Code）
┌──────────────────┐    审批卡/画面/🏁/🔓     ┌──────────────────────────┐
│  群「claude遥控器」 │ ◄────────────────────── │ hooks: PreToolUse / Stop  │
│                  │    ──────────────────►   │  · remote_approve 审批钩子 │
│  · 点 👍/👎 批操作  │    群消息=指令/表情=表决   │  · remote_done 完成通知    │
│  · 说话=打进终端    │                          │  · leave_sentry 键盘哨兵   │
│  · 「关闭离开模式」  │                          │ watcher: 群⇄tmux 遥控器    │
│  · 看窗口实时画面   │                          │ tmux: 状态色+待批横幅       │
└──────────────────┘                          └──────────────────────────┘
```

## 为什么做这个

Claude Code 跑长任务时人往往不在电脑前：它要删文件、要 push、要改配置——传统做法要么等着授权要么干脆不敢让它跑。这套方案把**决策权搬到手机**：低危操作不打扰你，中高危操作推卡到你手上，一个表情就能放行或拦停；同时群里还能直接对 Claude 说话、看它的实时画面。

## 电脑 → 手机：你会在群里收到什么

**① 审批卡**（Claude 想做中/高危操作时，四层结构，一眼看懂再决定）

```
🟡 离开模式审批（中危·超时默认同意）
来源：dev·myapp
任务：「给状态条加变色系统」
本步目的：改 watcher 前先备份原脚本，防止回滚丢代码
操作：修改文件 tmux_feishu_watch.py (位于 ~/.claude/remote)：import tomllib → import json
工具: Edit
──── 完整内容 ────
文件: /Users/you/.claude/remote/tmux_feishu_watch.py
──── 旧内容 ──── … ──── 新内容 ──── …
────────────────
ID: 05418
👇 单击本消息下方的 👍/👎 表情标签表决（一下即生效）
2/3分钟催办，15分钟未回按危险度自动裁决
```

**② 其它通知**

| 消息 | 含义 |
|---|---|
| 🏁 这轮回复说完了 | Claude 一轮任务结束，附上最后的回复内容（超长截断） |
| 【xxx 画面】 | 绑定窗口的终端画面快照（内容稳定 6 秒自动推） |
| ⏳ 催办 1/2 | 审批卡 2/3 分钟没人理时轻提醒 |
| 🔓 已自动解除 | 检测到你回到电脑动了键盘，离开模式自动关 |
| ✅ 收到 THUMBSUP → 已放行 | 表决结果留痕 |

## 手机 → 电脑：你在群里说话会发生什么

| 你发 | 效果 |
|---|---|
| 普通一句话 | 直接打进绑定的 tmux 窗口——等于坐到电脑前敲键盘，Claude 正常响应 |
| `打开离开模式` / `关闭离开模式` | **程序化**开关审批推送（watcher 关键词直处理，不依赖任何 AI 理解，≤12 字短句触发防误伤） |
| `#列表` | 列出电脑所有 tmux 窗口（名字/路径/程序/状态） |
| `#切 名字` | 换绑定目标（面板级要冒号：`#切 12:0.1`） |
| 点卡片消息下 👍/👎 | 表决。群里打字会被当指令，所以表决只认表情 |

## 审批安全模型

| 危险度 | 例子 | 行为 |
|---|---|---|
| 🟢 低危 | 读文件、搜索、`ls`/`git status`、rm 临时文件 | 秒过，不打扰手机 |
| 🟡 中危 | 改/写文件、普通命令 | 推卡表决，**15 分钟未回默认放行** |
| 🔴 高危 | 删除、`git push`、部署、sudo、docker rm | 推卡表决，**15 分钟未回默认拒绝** |

- 表决只认 👍/👎 表情反应（不产生消息，不污染指令通道）
- 钩子自身任何异常 → 自动回退本地弹问，绝不卡死任务
- 开关自锁保护：涉及开关本身的操作秒过（防止"关不掉"）

## 电脑端看得见的状态（tmux）

| 颜色/文字 | 含义 |
|---|---|
| 🟩 绿色窗口标签 | 干活中（含刚被手机放行） |
| 🟨 黄色 + 整行「🟡 待审批 05418…」横幅 | 中危操作在等手机表决 |
| 🟥 红色 + 整行「🔴 高危待审批…」横幅 | 高危在等，或刚被手机拒绝拦停 |
| ⬜ 灰色 | 空闲 |

不在 tmux 里的窗口降级为 macOS 系统横幅提醒。

## 键盘哨兵（自动解除）

离开模式下，系统真实键鼠闲置曾 ≥30 秒后又动了 → 判定"人回电脑了" → 自动关离开模式 + 🔓 通知手机。**只认真实 HID 输入**：SSH、脚本模拟都不算——远程操作永远不会把你的审批模式弄关。

## 安装

完整说明书见 **[INSTALL.md](INSTALL.md)**（10 步、含验收清单与飞书应用申请细节）。速览：

```bash
# 1. 飞书开放平台建自建应用（开 im 消息+表情权限），拉进群，拿 4 个值
# 2. 填凭据
cp config.example.json ~/.claude/remote/feishu.json && chmod 600 ~/.claude/remote/feishu.json
# 3. 铺文件 → 合并 hooks 注册 → 起 watcher → 装哨兵（INSTALL.md 第 3~8 步逐条命令）
```

**让 AI 替你装**：把本仓库丢给新电脑上的 Claude Code，说"照 README/INSTALL 装好并跑验收清单"即可——INSTALL.md 顶部有专门写给 AI 执行者的须知（哪几步自跑、哪步必须找你要凭据、验收失败查哪些日志）。

## 环境要求

| | |
|---|---|
| 系统 | macOS（全功能）；Linux 可用，键盘哨兵/系统横幅自动静默降级；Windows 建议 WSL2（等同 Linux） |
| 软件 | tmux ≥3.2 · Python3（标准库即可）· Claude Code |

## 安全须知（部署前读）

- 遥控器群里**任何成员**都能点 👍/👎 表决、普通文字会直接打进绑定窗口——群不要拉无关人员
- `feishu.json` 含 app_secret，保持 `chmod 600`，勿提交进任何仓库
- 手机与电脑不同时对同一会话动手（接力可用，并用会写冲突）
- 本仓库不含任何真实凭据/个人环境信息
